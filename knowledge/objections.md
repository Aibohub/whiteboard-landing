# Objections

If the client has no roteiro, ask for a simple idea or raw text.
If the client does not know the format, recommend 9:16 for Reels/Shorts and 16:9 for YouTube/site.
If the client is in a hurry, explain express delivery as an add-on by package.
If the client worries about trust, mention demos, Upwork review, order ID, email status and support ticket.
